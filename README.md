# 🧮 MATRIX LAB • Theory of Control (Mobile & Web Edition)

**MATRIX LAB** — это инженерный программный комплекс (Android Jetpack Compose + адаптивная Web-версия) для матричных вычислений, спектрального анализа и синтеза систем автоматического управления (ТАУ).

Приложение объединяет классическую линейную алгебру, высшие матричные функции и методы современной теории управления в пространстве состояний (`ẋ = Ax + Bu`, `y = Cx`).

---

## ✨ Ключевые возможности

### 1. ⚡ Базовая линейная алгебра и матричный анализ
Работа с тремя квадратными матрицами (**A**, **B**, **C** размерности от `2×2` до `7×7`), а также с прямоугольными матрицами и векторами произвольной размерности (`M×N` от `1×1` до `7×7`):
* **Арифметика матриц:** `A ± B`, `A × B`, цепочечные операции `A ± B ± C`, `A × B × C`, умножение на скаляр `k · A`.
* **Обращение и транспонирование:** нахождение обратной матрицы `A⁻¹` (метод Гаусса–Жордана с масштабированным выбором главного элемента и контролем числа обусловленности) и транспонированной матрицы `Aᵀ`.
* **Числовые характеристики:**
  * Определитель `det(A)` с защитой от переполнения и потери значимости.
  * След матрицы `Tr(A)`.
  * Численный ранг `rank(A)` на основе сингулярных чисел (односторонний метод вращений Якоби — One-sided Jacobi SVD без формирования `AᵀA`).
* **Матричные и векторные нормы:**
  * Норма Фробениуса `‖A‖_F = √(∑ |a_ij|²)` (вычисляется через устойчивую функцию `hypot`).
  * Спектральная норма (2-норма) `‖A‖_2 = σ_max(A)`.
* **Векторная алгебра:** скалярное произведение `(a · b)` для векторов любой размерности и векторное произведение `(a × b)` в 3D-пространстве.

### 2. 🎛 Спектральный анализ и канонические формы
* **Собственные значения (`λ_i`):** предварительная балансировка матрицы, приведение к верхней форме Хессенберга и итерационный QR-алгоритм со сдвигами Уилкинсона и исключительными сдвигами для периодических матриц. Поддержка как вещественных, так и комплексно-сопряженных спектров.
* **Собственные векторы (`v_i`):** решение систем `(A − λ_i I) v_i = 0` в комплексной арифметике с автоматическим выделением линейно независимых векторов для кратных корней и проверкой невязки `‖A v_i − λ_i v_i‖`.
* **Характеристический многочлен `p(λ)`:** построение полинома `det(λI − A) = λⁿ + c₁λⁿ⁻¹ + … + cₙ` методом Фаддеева–Леверье.
* **Комплексная Жорданова нормальная форма (ЖНФ):** вычисление структуры жордановых клеток по характеристике Вейра через ранги степеней нильпотентных матриц `(A − λ_i I)ᵏ`.
* **Вещественная Жорданова нормальная форма (РЖНФ):** формирование блочно-диагональной матрицы с вещественными клетками `2×2` вида `[ α  β ; −β  α ]` для комплексно-сопряженных пар собственных значений `α ± iβ`.

### 3. 📊 Анализ систем автоматического управления (ТАУ)
* **Анализ устойчивости непрерывных систем (`ẋ = Ax`):** спектральный критерий Гурвица — проверка расположения всех собственных значений в левой открытой полуплоскости (`Re(λ_i) < 0`), выявление пограничных случаев на мнимой оси и неустойчивости.
* **Анализ устойчивости дискретных систем (`x_{k+1} = A x_k`):** вычисление спектрального радиуса `ρ(A) = max |λ_i|` и проверка нахождения спектра строго внутри единичного круга (`ρ(A) < 1`).
* **Критерий управляемости Калмана:** построение матрицы управляемости `W_c = [ B, AB, A²B, …, Aⁿ⁻¹B ]` и проверка условия полной управляемости `rank(W_c) = n`.
* **Критерий наблюдаемости Калмана:** построение матрицы наблюдаемости `W_o = [ Cᵀ, (CA)ᵀ, …, (CAⁿ⁻¹)ᵀ ]ᵀ` и проверка условия полной наблюдаемости `rank(W_o) = n`.

### 4. 🚀 Синтез регуляторов и канонические преобразования ТАУ
* **Каноническая форма Фробениуса–Люенбергера (Управляемая сопровождающая форма):**
  * Построение невырожденного преобразования координат `x = T z`.
  * Вычисление канонических матриц `Ã = T⁻¹ A T` и `B̃ = T⁻¹ B`.
  * Автоматическая проверка подобия `‖T Ã T⁻¹ − A‖_F`.
* **Модальное управление (Формула Аккермана):**
  * Синтез закона обратной связи по состоянию `u = −K x`, обеспечивающего заданное расположение полюсов замкнутой системы `eig(A − BK) = {μ₁, …, μₙ}` по формуле `K = [ 0 … 0 1 ] · W_c⁻¹ · φ(A)`.
  * Поддержка как вещественных, так и комплексно-сопряженных желаемых полюсов с верификацией спектра замкнутой системы.
* **Линейно-квадратичный регулятор (LQR — Оптимальное управление):**
  * Минимизация квадратичного функционала качества `J = ∫ (xᵀ Q x + uᵀ R u) dt → min` при `Q = Qᵀ ≥ 0` и `R = Rᵀ > 0`.
  * Проверка положительной определенности матрицы `R` (разложение Холецкого) и неотрицательной определенности `Q` (симметричный метод Якоби).
  * Решение непрерывного алгебраического уравнения Риккати (CARE): `Aᵀ P + P A − P B R⁻¹ Bᵀ P + Q = 0` через матричную функцию знака матрицы Гамильтона с масштабированием Робертса–Бауэрса.
  * Вычисление матрицы оптимального регулятора `K = R⁻¹ Bᵀ P` и проверка асимптотической устойчивости замкнутой системы `A − BK`.

### 5. 🔬 Высшие матричные функции `f(A)`
* **Матричная экспонента `e^A`:** эталонный метод масштабирования и возведения в квадрат Хайэма (Higham Scaling and Squaring) на базе диагональной аппроксимации Паде `[13/13]`.
* **Главный матричный логарифм `ln(A)`:** метод обратного масштабирования (последовательное извлечение квадратных корней `A^(1/2ᵏ) → I`) с последующим разложением преобразования Кэли `Y = (X − I)(X + I)⁻¹` в ряд ареатангенса.
* **Квадратный корень матрицы `√A`:** аналитическая формула Кэли–Гамильтона для `2×2`, метод Бьёрка–Хаммарлинга для треугольных матриц и итерационный метод Денмана–Биверса с масштабированием Хайэма для матриц общего вида.
* **Матричные тригонометрические функции `sin(A)` и `cos(A)`:** масштабирование матрицы с разложением в ряды Тейлора, восстановлением через формулы двойного угла и проверкой тождества `sin²(A) + cos²(A) = I`.
* **Целая степень матрицы `Aᵏ`:** быстрое бинарное возведение в степень для положительных, нулевого и отрицательных показателей (`k ∈ [-100, 1000]`).

## 💻 Удобство интерфейса (UX / UI)
* **Единая дизайн-система (Android & Web):** темная тема *Matrix Lab Dark*, цветовое кодирование матриц (`Cyan` для **A**, `Purple` для **B**, `Amber` для **C**, `Emerald` для результатов).
* **Логическая группировка операций:** переключение между вкладками `⚡ Алгебра`, `🎛 Спектр и ТАУ` и `🚀 Синтез и f(A)` без длинной прокрутки экрана.
* **Быстрые действия:** генерация случайных матриц (`🎲 Рандом`), заполнение единичной матрицей (`𝐈 Единичная`), умный парсинг текста из буфера обмена (`📋 Вставить` — понимает таблицы из MATLAB, Python/NumPy, Excel и WolframAlpha).
* **Цепочечные вычисления:** перенос любого полученного результата обратно в матрицы **A**, **B** или **C** одной кнопкой (`➔ в A`, `➔ в B`, `➔ в C`).
* **Автономная история вычислений:** сохранение последних операций в памяти устройства (`SharedPreferences` на Android / `localStorage` в Web) с возможностью копирования и повторной подстановки.
* **Полная адаптивность:** поддержка телефонов, планшетов и двухколоночного режима (Split-View) на широких экранах ПК.

## 🛠 Технологический стек
* **Android-версия:** Kotlin, Jetpack Compose (Material 3), Coroutines, собственное высокоточное математическое ядро без внешних зависимостей, JUnit 4 для модульного тестирования.
* **Web-версия:** Чистый HTML5 + CSS3 (Responsive Grid / Flexbox) + Vanilla ES6+ JavaScript (работает локально в любом браузере без сервера и интернета).
